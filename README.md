## Descripcion de los programas

Este repositorio contiene 5 programas basicos en Python enfocados en la toma de decisiones mediante las estructuras `if`, `elif` y `else`:

1. `triangulo.py`: Determina si tres medidas pueden formar un triangulo y si este es equilatero, isosceles o escaleno.
2. `bisiesto.py`: Verifica si un ano ingresado es bisiesto aplicando la regla logica del calendario.
3. `notas.py`: Recibe una calificacion numerica del 0 al 100 y devuelve la letra correspondiente (A, B, C, D, F).
4. `mayor_menor.py`: Compara tres numeros ingresados e indica cual es el mayor y cual es el menor.
5. `entrada.py`: Calcula el precio de la entrada a un parque segun el rango de edad del usuario.
